## Featured Project

<div align="center">

# 🧰 XeooTools

### Free Tools for Everyday Technical Tasks

</div>

XeooTools is my main project — a growing collection of free web-based utilities.

The project combines a modern TypeScript frontend with a PHP backend and MySQL administration system.

### Current Tools

```text
Network
├── IP Lookup
└── DNS Lookup

Security
├── Security Utilities
└── Experimental Security Tools

Files
├── ZIP Inspector
└── File Utilities

Code
└── Developer Utilities

Image
├── Image Resize
├── Image Compress
└── Image Convert

SEO
└── SEO Utilities

Encoding
└── Encoding / Decoding Tools
```

---

<details>
<summary><strong>🌐 Network Tools</strong></summary>

<br>

### IP Lookup

Provides information about an IP address including:

- IPv4 / IPv6
- Hostname
- Country
- Region
- City
- Postal Code
- ASN
- Organization
- Timezone
- Coordinates

The lookup system uses external IP intelligence data to provide more reliable geolocation information.

### DNS Lookup

DNS analysis tool supporting common record types:

```text
A
AAAA
CNAME
MX
NS
TXT
SOA
CAA
SRV
ALL
```

Resolvers include:

```text
Cloudflare
Google
Quad9
```

</details>
